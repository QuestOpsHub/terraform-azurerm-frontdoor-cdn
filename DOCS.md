### Dns Zones

- `questopshub.site` is an Azure DNS zone.

- Hostinger Domains

    - dev: `devquestopshub.site`
    - qa: `qaquestopshub.site`
    - prod: `prodquestopshub.site`

- CNAME & TXT records for the above Hostinger Domains will be added to the `questopshub.site` DNS zone when this module is executed.
